# Frankenstein Game

A collaborative open-source game built by devs, artists, musicians, designers, and vibecoders adding whatever weird piece they can contribute.

There is no fixed final design. The game grows by stitching together good ideas.

## First contribution

1. Fork this repo.
2. Make a branch.
3. Add one small thing.
4. Open a pull request.

Your first contribution can be a mechanic, room, character, prop, sound, UI element, minigame, shader, animation, joke, bit of writing, or anything else that can become part of the monster.

## Ground rules

- Don't push directly to `main`.
- Don't delete or replace someone else's work just to make yours fit.
- Keep contributions reasonably self-contained when possible.
- Include a short note explaining what you added and how to try it.
- Credit assets you did not create and only submit things we are allowed to redistribute.
- Weird is good. Broken-the-whole-project is not.

## Philosophy

If someone adds a fishing minigame, someone else adds a mech, and someone else builds a haunted gas station, those things now exist in the same universe. We figure out how to connect them.

Think open-source game development as an exquisite corpse.

**No idea what the final game is. That's the point.**
